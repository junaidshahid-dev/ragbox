# Acme Tools — Product Specifications (sample document)

## ToolMaster 3000

Brushless 20V motor, 1,800 RPM no-load speed, 60 Nm max torque. Battery: 4.0 Ah
lithium-ion, 90-minute fast charge. Weight 1.6 kg. IP54 dust and splash rating.

## Accessories

The quick-release chuck accepts all standard 6.35 mm hex bits. The carry case
includes a 32-piece bit set and a belt clip.

## Compliance

Certified to CE and FCC Part 15 Class B. Operating temperature 0-40 C.
